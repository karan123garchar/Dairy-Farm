================================================================================
  5. SCREENS — WHAT EACH SCREEN CONTAINS
================================================================================

-- SplashScreen ---------------------------------------------------------------
  • Full-screen animated intro (logo + brand name)
  • Auto-navigates to /login after delay

-- LoginScreen ----------------------------------------------------------------
  • Email + Password TextFields
  • ElevatedButton "Login"
  • TextButton "Register" navigation
  • Logo / brand header
  • Admin / User role detection

-- RegisterScreen -------------------------------------------------------------
  • Name, Email, Password, Confirm Password TextFields
  • ElevatedButton "Create Account"
  • TextButton "Already have an account? Login"

-- HomeScreen -----------------------------------------------------------------
  • AppBar with menu (Drawer) + profile icon
  • Hero banner section
  • Stats summary cards (total animals, today yield, etc.)
  • Quick action buttons / grid
  • Recent activity section
  • BottomNavBar

-- AnimalListingScreen --------------------------------------------------------
  • AppBar with search icon
  • Search/filter bar
  • ListView or GridView of animal cards
  • Each card: animal image, name, tag ID, breed, status badge
  • Tap → navigates to AnimalDetailScreen
  • BottomNavBar

-- AnimalDetailScreen ---------------------------------------------------------
  TABS: Overview | Gallery | Milk Production | Health Record

  Hero Header:
    • Full-width animal image (240px height)
    • Gradient overlay (dark bottom)
    • "Elite Producer" badge pill
    • Tag ID pill
    • Animal name (bold white text)
    • Location/stable text below name

  Tab 1 — Overview:
    • Specs Grid (2x2): Age, Weight, Breed, Status
    • Daily Average Yield Banner (dark green card with big number)
    • Health Summary Card (LinearProgressIndicator + score)
    • Genetic Markers Card (Wrap of chip tags)
    • Recent Activity Card (timeline with icon + title + time)

  Tab 2 — Gallery:
    • 2-column GridView of media cards
    • Each card: image, tag badge (top-left), title (bottom)
    • Video cards: red VIDEO badge + duration + play button overlay
    • Tap → fullscreen media viewer dialog
    • Viewer: InteractiveViewer (pinch to zoom), play/pause toggle
    •         Slider for video progress, share/download/info buttons

  Tab 3 — Milk Production:
    • Milk Stats Grid (2x2):
        - Avg Fat Content
        - Avg Protein
        - Days in Milk (DIM)
        - Total Lactation
    • Recent Milking History list:
        - Today, Yesterday, 2 days ago, 3 days ago
        - Each row: day label + AM/PM sessions + total liters

  Tab 4 — Health Record:
    • Vitals Grid (temperature, heart rate, etc.)
    • Vaccination Status list (Brucellosis, Anthrax, FMD)
    • Veterinary Consultation Log (date, title, notes, vet name)

-- AnimalGalleryScreen --------------------------------------------------------
  • Search bar at top
  • Category filter chips (All, Anatomical, Routine, Health)
  • GridView of media items (photos + videos)
  • Video items: play overlay + duration badge
  • Tap → fullscreen viewer dialog

-- BreedCatalogScreen ---------------------------------------------------------
  • List of cattle/buffalo breeds
  • Each card: breed image, name, origin, avg yield, traits
  • Info chips / tags for breed characteristics

-- MilkYieldScreen ------------------------------------------------------------
  • AppBar with chart icon button (snackbar action)
  • Header section (title + subtitle)
  • Today's Production Card:
      - Morning and Evening session boxes (with icons)
      - Total liters (large bold number)
      - Percentage change badge (+4.2% from yesterday)
  • Month-to-Date dark card:
      - Total liters produced
      - LinearProgressIndicator (72% of monthly goal)
      - Progress text label
  • Milk Quality and Fat Metrics Card:
      - Avg Fat Content 8.2%
      - Avg SNF Level 8.8%
      - Chilled Storage Temp 4.0C
  • Top Performing Cattle Card:
      - Animal image + name + tag + avg yield + star icon

-- HealthScreen ---------------------------------------------------------------
  • Health summary stats cards
  • Animal health status list
  • Vaccination schedule
  • Alert/warning cards for sick animals

-- FeedScreen -----------------------------------------------------------------
  • Feed inventory list
  • Daily feed schedule per animal/group
  • Nutrition info cards

-- ProductsScreen -------------------------------------------------------------
  • Farm product listings
  • Product cards with image, name, price, details

-- ProfileScreen --------------------------------------------------------------
  • User avatar + name + role badge
  • Profile info fields (name, email, phone)
  • Settings options list
  • Logout button

-- AboutScreen ----------------------------------------------------------------
  • Farm name and logo
  • Farm description text
  • Contact info (address, phone, email)
  • App version info

-- AdminPanelScreen -----------------------------------------------------------
  • Admin-only full dashboard
  • User management section (list + add/edit/delete users)
  • Animal CRUD (Add/Edit/Delete animals)
  • Reports and analytics sections
  • System settings controls

  Usage  : const DairyBottomNavBar(selectedIndex: 0)

  Usage  : drawer: const AdminDrawer()
  Items  : All UserDrawer items + Admin Panel link at top

  General purpose drawer (used in some screens as alternative)

-- CowHeadIcon (cow_head_icon.dart) -------------------------------------------
  Usage  : CowHeadIcon(size: 40, color: Colors.white)
  Desc   : Custom cow head icon (drawn with CustomPainter or SVG)
  Params : size (double), color (Color)
  Used   : Image error fallbacks, loading states, nav icons

================================================================================
  10. DECORATION AND STYLING
================================================================================

  BoxDecoration properties used in this project:
  -----------------------------------------------
  color          → Solid fill color
  borderRadius   → Rounded corners (BorderRadius.circular(N))
  border         → Outline (Border.all(color: ..., width: 1))
  gradient       → LinearGradient (hero, banners, bars)
  boxShadow      → Drop shadows on cards
  shape          → BoxShape.circle for circular avatars

  Common border radius values:
  ----------------------------
  4    → Tiny elements (bar corners, small chips)
  8    → Small tags and badges
  10   → Small cards and vitals tiles
  12   → Standard cards (most cards)
  14   → Large inputs and hero cards
  16   → Section-level large cards
  20   → Avatar clips (CircleAvatar radius: 20)
  circular → Full pill shapes (BorderRadius.circular(100))

  Gradients used:
  ---------------
  Hero image overlay     : Black transparent, top to bottom
  Dark yield banner      : Deep green shades, top to bottom
  Gallery card overlay   : Black multi-stop (dark top + dark bottom)
  Top-highlight gradient : Light to dark green (bars/buttons)

================================================================================
  12. NAVIGATION PATTERNS
================================================================================

  Pattern                 Code
  -----------------------------------------------------------
  Named route push        Navigator.pushNamed(context, '/home')
  Named route replace     Navigator.pushReplacementNamed(context, '/login')
  Push widget             Navigator.push(context, SmoothPageRoute(builder: (_) => Screen()))
  Pop (go back)           Navigator.pop(context)
  Show Dialog             showDialog(context: context, builder: (_) => Dialog(...))
  Show BottomSheet        showModalBottomSheet(context: context, builder: ...)

  Custom Page Transition : SmoothPageRoute (smooth_page_route.dart)
  → Used for: AnimalDetailScreen, MilkYieldScreen, and similar screens
